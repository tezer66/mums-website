### App Privacy ("nutrition label")

Choose **"Yes, we collect data"**, then tick these:

| Data type | Linked to the user? | Used for tracking? | Purpose |
|---|---|---|---|
| Contact Info → Name | Yes | No | App Functionality |
| Contact Info → Email Address | Yes | No | App Functionality |
| User Content → Other User Content (journal entries) | Yes | No | App Functionality |
| Identifiers → User ID | Yes | No | App Functionality |

Don't tick anything else. The app has no ads and no tracking, and payments happen outside the app.
